# Creative Frontend Inspiration Sources

Use these as research categories and search targets. Do not copy designs,
assets, content, code, or brand identity. Extract patterns: layout rhythm,
motion language, interaction mechanics, content choreography, and production
constraints.

## Primary Reference Categories

### Curated Galleries

- Awwwards: premium creative websites, scrollytelling, WebGL, agency sites.
- SiteInspire: editorial, portfolio, studio, and art-directed web design.
- Godly.website: contemporary high-polish landing pages and product sites.
- Land-book: landing-page patterns and conversion-oriented composition.
- Httpster: independent studio and portfolio aesthetics.
- Lapa Ninja: landing-page structure and product storytelling.

Search keywords:

- `Awwwards scrollytelling product website`
- `Awwwards GSAP ScrollTrigger landing page`
- `premium portfolio website motion UI`
- `cinematic agency website interaction design`
- `editorial landing page kinetic typography`

### Motion And Interaction References

- GSAP showcase and ScrollTrigger demos.
- Framer / Motion for React examples.
- Codrops: interaction experiments, image reveals, transitions.
- Rive community examples for interactive vector motion.
- LottieFiles only for vector motion pattern discovery, not generic stock use.

Search keywords:

- `GSAP ScrollTrigger pinned section case study`
- `scroll scrub timeline landing page`
- `split text reveal kinetic typography`
- `mask reveal image transition`
- `SVG path animation landing page`
- `Rive interactive button microinteraction`

### WebGL / 3D References

- Three.js examples for technical feasibility.
- React Three Fiber examples and Drei patterns.
- ShaderToy for shader ideas, only when shaders are justified.
- Bruno Simon-style portfolio references for interaction mechanics, not copying.

Search keywords:

- `React Three Fiber product hero`
- `Three.js shader background premium website`
- `WebGL particle system landing page`
- `2.5D parallax website layers`

### Product Storytelling

- Stripe-style product explanation for clarity, not visual cloning.
- Linear-style restraint and hierarchy for product quality.
- Apple-style scroll narrative references for pacing and content reveal.
- Editorial long-form interactives from major publications for scrollytelling
  structure.

Search keywords:

- `product storytelling landing page scroll animation`
- `interactive product explanation scroll driven`
- `editorial scrollytelling web design`
- `sticky section product narrative`

## How To Use References

For each reference, capture:

1. Why it works for the project goal.
2. The layout pattern.
3. The motion pattern.
4. The interaction mechanic.
5. What not to copy.
6. Performance and accessibility risks.
7. A simpler fallback for mobile and reduced motion.

## Output Format For Inspiration Notes

```markdown
## Reference Pattern
- Source/category:
- Useful for:
- Layout pattern:
- Motion pattern:
- Interaction mechanic:
- Implementation candidate:
- Risks:
- Reduced-motion/mobile fallback:
- Do not copy:
```
