# Archive

earlier states of Hipson and are **not** current documentation; current behaviour is in
the top-level `README.md` and the live documents under `docs/`.

| Folder | Contents |
|---|---|
| `2026-q2-planning/` | May–June 2026 roadmaps, audit findings, readiness scorecards, autonomous-loop logs and the persistent-runtime spec. |
| `STABILIZATION-1.6.md` | The four read-only reviews of 1.6.0 and the findings fixed in 1.7 (referenced by the changelog and DEPRECATIONS). |
| `plan-1.8.md` | The 1.8 plan (agent-facing tool), shipped in 1.8.0; the baseline and measurements it set. |
| `handoff.md` | An early setup and handoff snapshot with old verification counts. |
| `2026-05-audit/` | The May 2026 project audit bundle (claims matrix, command log, decision brief, README proposal). |
